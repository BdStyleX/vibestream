# VibeStream (Flutter + Firebase)

Features: email sign-up/login, For You feed (real posts from Firestore), photo and video upload, Remix Poll,
likes, VibeSnips vertical video pager, profile, report/block/delete post, in-app account deletion.

Not included yet (Phase 2): Live Pods, Creator Vault payments, Following feed, notifications.

Start with `ADMIN_TASKS.md`. Files:
- `setup.sh` - generates the Android project and applies required settings
- `firestore.rules`, `storage.rules` - paste into the Firebase console
- `PRIVACY_POLICY.md`, `PLAY_STORE_LISTING.md` - templates for publishing

Status: code was written without a Flutter toolchain, so it has not been compiled yet. Send any build errors back to fix.
